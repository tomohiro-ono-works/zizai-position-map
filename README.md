# DX案件ワークスペース

案件情報の項目定義・入力・分析を、ブラウザ上で行う単一HTMLのサンプルです。

## 使い方

`index.html` をブラウザで開いてください。サーバーの起動は不要です。

## データの取り扱い

- リポジトリには架空のサンプルデータのみを含めます。
- 実際の案件名、個人情報、社内情報、書き出したYAML/JSONはコミットしないでください。
- 編集した内容はブラウザのローカルストレージに保存されます。YAMLファイルへの保存・読み込みは画面から操作できます。

## Gitへの反映

`main` への直接プッシュを避け、作業ブランチからPull Requestを作成してください。
コミットにはGitHubの `noreply` アドレスを使用してください。
