YAMLで入力項目を編集

項目の順序でルートキーが決まります。編集後に「定義を適用」を押してください。

対応形式：`columns`、`name`、`type`、`options`、`cardinality`、`allowDetail`。

1:Nは直前の項目に対する関係です。「＋」で同じ親の子項目とその下位フォームを追加します。

案件データをYAMLで編集

項目名ごとに親子関係を記述します。変更後は表に反映できます。

1:Nはリスト（- value）、1:1は value で表現します。詳細メッセージは detail に入力します。

マトリクス設定
セル値の色
値のフィルター

行・列は値のみを表示します。同じ上位値は見出しセルを結合します。セル内の重複文字列は排除します。列見出しの右端をドラッグすると列幅を変更できます。

マトリクス設定をYAMLで編集

rows / columns / values / filters / tooltip / colors を編集できます。フィールド名と値は引用符で指定してください。
